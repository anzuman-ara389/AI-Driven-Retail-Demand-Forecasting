# AI-Driven Retail Demand Forecasting and Intelligent Inventory Decision Support for Food Waste Reduction

# Overview

This project presents an end-to-end MLOps pipeline for AI-driven retail demand forecasting and intelligent inventory decision support for food waste reduction. The system simulates a production-style workflow in which live retail sales events are generated, submitted through FastAPI APIs, stored in a SQLite database, preprocessed, transformed through feature engineering, used for demand prediction, monitored for data drift, and automatically retrained when significant drift is detected.

The project demonstrates:

* Live API-based data ingestion
* Data preprocessing and feature engineering
* Machine learning model training and comparison
* Demand prediction through FastAPI
* Inventory assessment and waste-risk classification
* Intelligent recommendation generation
* Drift detection and monitoring
* Automatic model retraining
* Model versioning and artifact tracking
* Streamlit dashboard
* Docker-ready deployment

# Features

## API-Based Data Ingestion

Live retail sales events are generated by an external client and sent to the FastAPI backend.

Endpoint:

```text
POST /sales-event
```

# Data Preprocessing

The preprocessing pipeline performs:

* Missing value handling
* Duplicate removal
* Data type conversion
* Feature engineering
* Label encoding
* Processed dataset creation

# Feature Engineering

Engineered features include:

* product_encoded
* category_encoded
* store_id
* day_of_week
* is_weekend
* is_holiday
* promotion
* promotion_active
* temperature
* unit_price
* expiry_days
* short_expiry
* current_stock
* waste_quantity

# Model Training and Comparison

The project trains and compares:

* RandomForestRegressor
* XGBoostRegressor

The best-performing model is selected using Cross-Validation RMSE (TimeSeriesSplit).

Tracked metrics:

* MAE
* RMSE
* R² Score
* Train RMSE
* Cross-Validation RMSE
* Generalization Gap

# Prediction Pipeline

Endpoint:

```text
POST /predict-demand
```

Pipeline:

1. Receive request
2. Build engineered features
3. Predict demand
4. Assess inventory
5. Classify waste risk
6. Generate intelligent recommendation
7. Store prediction log

# Drift Detection

The system compares a reference window of 1000 records with the latest 300 records using relative mean shift.

Threshold:

```text
0.15
```

Endpoint:

```text
POST /drift-check
```

# Automatic Retraining

When drift exceeds the threshold, the system automatically retrains the models, selects the best model using Cross-Validation RMSE, versions the model, and updates the production model.

Endpoint:

```text
POST /auto-retrain
```
